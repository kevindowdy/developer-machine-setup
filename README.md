# developer-machine-setup
Repository for storing local developer configurations, scripts and settings.

## Instructions for installing VS Code Coniguration

### Install Settings.json in GUI
1. Open VS Code
2. CMD + Shift + P
3. Preferences: Open User Settings (JSON)
4. Paste settings.json in window

### Install Keybindings.json in GUI
1. Open VS Code
2. CMD + Shift + P
3. Preferences: Open Keyboard Shortcuts (JSON)
4. Paste keybindings.json in window
